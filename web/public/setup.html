⚠️ Configuration Requise

Pour utiliser l'application, vous devez configurer Supabase.

Variables à ajouter sur Vercel :

VITE_SUPABASE_URL = votre_url_supabase
VITE_SUPABASE_ANON_KEY = votre_cle_supabase

Étapes :

  1. Créez un projet sur supabase.com
  2. Allez dans Settings → API
  3. Copiez l'URL et la clé anon
  4. Sur Vercel : Settings → Environment Variables
  5. Ajoutez les 2 variables ci-dessus
  6. Redéployez l'application
